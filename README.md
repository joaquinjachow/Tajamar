## 📋 Descripción del Proyecto

**Tajamar Molduras** es un sitio web corporativo moderno desarrollado para una empresa familiar de maderas y molduras con más de 25 años de experiencia en el mercado. El proyecto se enfoca en presentar los productos de manera atractiva, facilitar el contacto con clientes y generar confianza a través de un diseño profesional.

### 🎯 Objetivos Alcanzados

- ✅ **Presencia digital profesional** para empresa tradicional
- ✅ **Catálogo interactivo** de productos con carrusel optimizado
- ✅ **Formulario de contacto** con validaciones robustas
- ✅ **Diseño responsive** perfecto en todos los dispositivos
- ✅ **Performance optimizada** con lazy loading y optimización de imágenes
- ✅ **SEO optimizado** con meta tags dinámicos

- **Tailwind CSS 3.4.1** - Framework CSS utility-first

- **Lazy Loading** - Carga diferida de contenido
- **Intersection Observer** - Detección de elementos en viewport

- **ESLint** - Linting de código

## 🚀 Instalación y Configuración

### **Prerrequisitos**
- Node.js 18+ 
- npm o yarn

### **Pasos de instalación**

```bash
# Clonar el repositorio
git clone https://github.com/tu-usuario/tajamar-molduras.git

# Navegar al directorio
cd tajamar-molduras

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Abrir en el navegador
http://localhost:3000
```

### **Scripts disponibles**

```bash
npm run dev      # Servidor de desarrollo
npm run build    # Build de producción
npm run start    # Servidor de producción
npm run lint     # Linting de código
```
